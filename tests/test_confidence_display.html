Confidence Score Display - Before & After Fix

Test Case 1: Normal Confidence (95%)

Backend Response:

{"confidence": 95}

Before Fix:

❌ Issue: No validation, could display incorrectly
95%

After Fix:

✅ Fixed: Validated and constrained
const confidence = Math.min(Math.max(parseFloat(95) || 0, 0), 100);
95%

Test Case 2: Edge Case - String Value ("80")

Backend Response:

{"confidence": "80"}

Before Fix:

❌ Issue: String not converted, might display as "80%" width

After Fix:

✅ Fixed: Converted to number with parseFloat()
const confidence = Math.min(Math.max(parseFloat("80") || 0, 0), 100);
80%

Test Case 3: Edge Case - Out of Range (150)

Backend Response:

{"confidence": 150}

Before Fix:

❌ Issue: Width would be 150%, breaking layout

After Fix:

✅ Fixed: Constrained to max 100%
const confidence = Math.min(Math.max(parseFloat(150) || 0, 0), 100);
100%

Test Case 4: Edge Case - Null/Undefined

Backend Response:

{"confidence": null}

Before Fix:

❌ Issue: Would display as "null%" or error

After Fix:

✅ Fixed: Defaults to 0%
const confidence = Math.min(Math.max(parseFloat(null) || 0, 0), 100);
0%

Summary of Fix

What was changed:

  • Added confidence validation: Math.min(Math.max(parseFloat(result.confidence) || 0, 0), 100)
  • Ensures value is always a number between 0-100
  • Rounds display value: Math.round(confidence)
  • Uses validated value for both width and text display

Benefits:

  • ✅ Confidence bar width always matches percentage text
  • ✅ Handles edge cases gracefully
  • ✅ No layout breaking from out-of-range values
  • ✅ Consistent display across all browsers
